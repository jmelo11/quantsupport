# Google Material Symbols

The unmodified SVGs in this folder are Material Symbols **Outlined**, 24 px,
from [google/material-design-icons](https://github.com/google/material-design-icons),
pinned to commit `10ecc14790612ca8fd164e3f4ffe9c16fc50d5b7`.

Source paths: `symbols/web/NAME/materialsymbolsoutlined/NAME_24px.svg`.
Copyright Google LLC. Distributed under [Apache License 2.0](LICENSE.txt).

`MaterialIcons.cs` renders these embedded vectors in QuantSupport teal for the
Office ribbon and panel actions. Excel needs no network connection, installed
icon font, or external image files. The source geometry is unchanged.
