# Glossary

**AAD**  
Algorithmic or automatic adjoint differentiation. Used to calculate many input sensitivities efficiently.

**Basis**  
The spread or value difference between related rates, curves, currencies, or instruments.

**CSA**  
Credit Support Annex. Defines collateral rules for a netting agreement.

**CVA / DVA / FVA**  
Credit, debit, and funding valuation adjustments.

**Discount curve**  
A term structure used to convert future cashflows to present value.

**DV01 / PV01**  
Change in value for a one-basis-point rate move. Confirm whether a report is signed and whether it uses market-quote or zero-rate risk.

**EPE / ENE**  
Expected positive and expected negative exposure at a future date.

**Fixing**  
An observed historical index value used for a coupon whose reset date has passed.

**Forward curve**  
A term structure used to forecast floating index rates.

**LGM**  
Linear Gaussian Model, used for rates and multi-factor market simulation.

**Market quote sensitivity**  
Derivative of value with respect to a calibration quote, including bootstrap dependencies.

**Netting set**  
Trades that legally offset for exposure and collateral calculations.

**Pillar**  
A dated or tenored calibration input associated with a curve or volatility object.

**Pricing context**  
The collection of observable and constructed market data used during evaluation.

**Volatility surface / cube**  
An implied-volatility object indexed by expiry and strike, with a cube adding underlying tenor.

**XVA**  
Collective term for valuation adjustments arising from credit, funding, collateral, capital, and related effects.
