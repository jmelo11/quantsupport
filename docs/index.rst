QuantSupport API Reference
==========================

.. toctree::
   :maxdepth: 2

   python/index

This reference documents the callable interfaces of the Python package and the
Excel XLL: declarations, parameter meanings and units, default behavior, return
values, properties, and errors. It is generated from the packaged Python type
stubs and the Excel registration metadata used by the add-in.

For explanations of the financial components and worked examples, use the
`QuantSupport Book <../index.html>`_. Native Rust types and traits are documented
in the `Rust API reference <https://docs.rs/quantsupport>`_.
