# Valuation examples

Each product family has its own Cargo workspace package, source and configuration.
Run these commands from the repository root:

| Product | Package | Command |
| --- | --- | --- |
| [Swaps](swaps/README.md) | `valuation-swaps` | `cargo run -p valuation-swaps` |
| [Bonds](bonds/README.md) | `valuation-bonds` | `cargo run -p valuation-bonds` |
| [Caps and caplets](caps/README.md) | `valuation-caps` | `cargo run -p valuation-caps` |
| [Loans](loans/README.md) | `valuation-loans` | `cargo run -p valuation-loans` |
