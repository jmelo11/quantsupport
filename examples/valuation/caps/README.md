# Cap and caplet valuation

Price a single SOFR caplet and a quarterly cap strip with the Black pricers.
The example uses the same illustrative 2026-02-24 curves and Black caplet
surface as the Python walkthrough and prints raw quote derivatives.

Run from the repository root:

```bash
cargo run -p valuation-caps
```

The [Python caps walkthroughs](../../../bindings/python/examples/valuation/caps/README.md)
are isolated in the matching product folder. Return to the
[valuation catalog](../README.md).
